# 🔧 Руководство по отладке

## Проблема: Кнопка "Начать приключение" не работает

### Шаг 1: Убедитесь что зависимости установлены

```bash
npm install
```

Подождите пока установятся все пакеты (~2-3 минуты).

### Шаг 2: Запустите приложение

```bash
npm run dev
```

Вы должны увидеть что-то вроде:
```
  VITE v5.0.8  ready in 500 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
```

### Шаг 3: Откройте консоль браузера

1. Откройте http://localhost:5173
2. Нажмите **F12** (или Cmd+Option+I на Mac)
3. Перейдите на вкладку **Console**
4. Посмотрите есть ли ошибки (красным цветом)

### Частые ошибки и решения:

#### ❌ "Cannot find module 'zustand'"
**Решение:**
```bash
npm install zustand
```

#### ❌ "Unexpected token" или "SyntaxError"
**Решение:**
```bash
rm -rf node_modules package-lock.json
npm install
```

#### ❌ Кнопка не реагирует, но ошибок нет
**Решение:**
1. Проверьте что вы кликаете именно на кнопку
2. Откройте вкладку **React DevTools**
3. Проверьте что `phase` = 'landing'

### Шаг 4: Проверка состояния

Добавьте в консоли браузера:
```javascript
// Откройте консоль (F12) и вставьте:
console.log(window.location.href);
```

### Шаг 5: Тест кнопки

Попробуйте добавить `console.log` в код:

Откройте `src/components/StartScreen.tsx` и измените:

```typescript
const handleStart = () => {
  console.log('Кнопка нажата!'); // ДОБАВЬТЕ ЭТУ СТРОКУ
  incrementCitizensCount();
  setPhase('chapterMap');
};
```

Теперь при клике должно появиться сообщение в консоли.

### Шаг 6: Проверка React

В консоли браузера:
```javascript
// Проверьте что React загружен
console.log(React);
```

### Быстрое решение (если ничего не помогло):

```bash
# 1. Полная очистка
rm -rf node_modules package-lock.json dist

# 2. Переустановка
npm install

# 3. Запуск
npm run dev
```

### Проверка портов

Если порт 5173 занят:
```bash
npm run dev -- --port 3000
```

### Логи ошибок

Если видите ошибки, пришлите скриншот или текст:
1. Ошибки в терминале (где запущен `npm run dev`)
2. Ошибки в консоли браузера (F12)

### Альтернативный тест

Создайте тестовый файл `test.html`:
```html
<!DOCTYPE html>
<html>
<body>
  <button onclick="alert('Работает!')">Тест</button>
</body>
</html>
```

Откройте его в браузере. Если эта кнопка работает - проблема в React коде.

---

## Скорее всего проблема в:

1. ⚠️ **Не установлены зависимости** (самая частая причина)
   - Решение: `npm install`

2. ⚠️ **Ошибки компиляции**
   - Решение: Проверьте терминал где запущен dev сервер

3. ⚠️ **JavaScript отключен в браузере**
   - Решение: Включите JavaScript

4. ⚠️ **Блокировщик рекламы**
   - Решение: Отключите для localhost

---

## Что НЕ может быть проблемой:

✅ Код кнопки написан правильно
✅ Обработчик события подключен
✅ Store настроен корректно
✅ Навигация работает
